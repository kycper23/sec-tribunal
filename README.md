# SEC Tribunal

[![CI](https://github.com/kycper23/sec-tribunal/actions/workflows/ci.yml/badge.svg)](https://github.com/kycper23/sec-tribunal/actions/workflows/ci.yml)

**A benchmark for bought intelligence.** Code scores a US company's SEC filings with no model at all. Three AI agents argue the same evidence on one Orbio key. The gap between them — the **Narrative Gap** — is the product. In Blind Trial mode the evidence is sealed at a past date and reality grades the verdict.

**Live:** https://sec-tribunal.vercel.app · [Scoreboard](https://sec-tribunal.vercel.app/scoreboard) · [Methodology](https://sec-tribunal.vercel.app/methodology) · [A finished ruling](https://sec-tribunal.vercel.app/dossier/TSLA)

## Results

19 US companies, evidence sealed at **2025-03-31**, each graded against its next annual 10-K. One further company (CAT) was excluded: no annual revenue after the seal was found under the standard XBRL tags.

| Contestant | Correct calls | CREDIT spent | Correct per CREDIT | Mean \|gap\| | Charges sustained |
|---|---|---|---|---|---|
| Always say RISE (naive baseline) | 16 / 19 | 0 | — | — | — |
| Clerk (code only, no model) | 16 / 19 | 0 | — | — | — |
| Tribunal — one provider (Claude Sonnet 5 + Fable 5) | 18 / 19 | 3.98 | **4.52** | 9.9 | 17.7% |
| Tribunal — three providers (GPT-5.2 + Gemini 3.1 Pro + Fable 5) | 18 / 19 | 4.46 | 4.03 | 11.3 | **24.7%** |

- **The clerk alone does no better than always guessing "rise."** A health score is not a revenue forecast; we report this rather than hide it.
- **Both tribunals beat both baselines, in the same two cases** — NKE (the arithmetic said rise, revenue fell) and BA (the arithmetic said fall, revenue rose).
- **Provider diversity bought scrutiny, not accuracy.** The three-provider tribunal sustained a larger share of charges and drifted further from the arithmetic, but called identical outcomes at 12% higher cost.
- **19 companies is a small sample.** A first measurement, not a verdict on the models.

## How it works

```
ticker ──► SEC EDGAR (XBRL companyfacts + 8-K docket)
               │
               ├──► Clerk: deterministic score 0–100 ──────────────┐
               │                                                    │
               └──► Brief ──► Skeptic ──► Advocate ──► Skeptic      │
                                                      (rebuttal)    │
                                                          │         │
                                       brief without clerk score    │
                                                          ▼         ▼
                                                      Arbiter ──► Narrative Gap
                                                  verdict + revenueCall
```

1. **Evidence.** SEC EDGAR only. Among fallback tags the freshest one wins; metrics not reported for 400+ days are marked `STALE` in the brief.
2. **The clerk.** Five 20-point sub-scores: growth, profitability, earnings quality, leverage, liquidity. Missing data scores neutral, never as a penalty. Financial institutions (SIC 6000–6799) get neutral leverage and liquidity.
3. **The case.** The Skeptic files charges, the Advocate rebuts, the Skeptic replies.
4. **The ruling.** A Zod-validated verdict: a score, each charge with status and category, and an explicit `revenueCall` with confidence — separate from the score, because a healthy company can have falling revenue.
5. **The reveal.** Blind Trial evidence is redacted by SEC filing date; the outcome is read from the first reporting period after the last one known at the seal.
6. **Ask the Arbiter.** After the verdict, three fixed questions — why it departed from the arithmetic, what would change its mind, which charge came closest to falling. No free-text input, so no prompt-injection surface; each answer shows its own model and CREDIT cost.

## What this gives Orbio

Orbio made inference a tradable unit. SEC Tribunal treats it as a measurable one.

- **One key, three providers, one file to change.** Every role runs on a single Orbio key; the roster assigns models and fallbacks, and an environment variable swaps any of them.
- **Every ruling is a receipt.** The Court Bill shows the model that *actually* answered each call — including fallbacks — with tokens and cost read from Orbio's `usage` block. A ruling burns about **0.22 CREDIT**.
- **Return per CREDIT, with the data to check it.** The scoreboard reports correct calls per CREDIT for each configuration, and the JSON behind it is in this repository.
- **A treasury you can see.** The home page reads the key's live balance from Orbio's `/key` endpoint. 100 free trials a day are funded from our own CREDIT, with a per-IP limit and a reserve floor that stops free trials before the balance runs out.
- **No CREDIT burned on an empty brief.** Filers without usable us-gaap data (for example 20-F ADRs) are refused before any model call.

## What went wrong, and how we caught it

Each was a real bug in this repository, found by checking output against source data.

1. **Interest coverage mixed fiscal years.** FY2025 operating income was divided by FY2023 interest expense, flattering Apple's leverage. Coverage now requires matching periods. Apple: 89 → 82.
2. **Banks were scored like manufacturers.** A bank's negative operating cash flow reflects its loan book, not a liquidity crisis. JPMorgan: 49 → 58.
3. **The Court Bill overstated savings.** We treated Orbio's `usage.cost` as a discounted price and derived a "list price" from it. It is already list price; the discount lives in what CREDIT costs on the order book. The bill now reports CREDIT burned, not invented savings.
4. **The reveal showed last year as the future.** A later 10-K restates the prior year as a comparative column filed after the seal. Filtering "future" by filing date resurfaced a known year; it is now filtered by reporting period.
5. **The judge was anchoring on the clerk.** With the clerk's score in the brief, Tesla's gap was −2. With it removed, −12. The first number measured agreement, not judgment.

## Known limits

- Free-trial counters and IP limits are held in memory per serverless instance.
- No banking model (ROE, net interest margin, capital ratios).
- A fact without a `filed` date falls back to its period end for the Blind Trial cutoff.
- The clerk cannot call revenue direction; its 60-point threshold is a naive reference line.
- `app/api/followup/route.ts` duplicates the completion-with-fallback logic from `agents.ts` rather than modify a module frozen during the backtest.

## Run it

```bash
npm install
cp .env.example .env.local        # add your Orbio key
npm run dev                       # http://localhost:3000
npm run brief AAPL                # the clerk's score for any ticker — no model calls, no cost
npm test
```

**Reproduce the scoreboard** (about 4.5 CREDIT per configuration, ~40 minutes each):

```bash
# three-provider run: set OPENROUTER_MODEL_PROSECUTION and OPENROUTER_MODEL_DEFENSE in .env.local
npm run backtest -- AAPL MSFT NVDA AMZN GOOGL META TSLA INTC AMD ORCL NFLX DIS NKE SBUX KO PG COST CAT BA F \
  --cutoff=2025-03-31 --out=../bt-multi.json

# single-provider run: remove those two variables, then
npm run backtest -- AAPL MSFT NVDA AMZN GOOGL META TSLA INTC AMD ORCL NFLX DIS NKE SBUX KO PG COST CAT BA F \
  --cutoff=2025-03-31 --out=../bt-single.json

npm run backtest:merge -- --multi=../bt-multi.json --single=../bt-single.json --out=data/backtest-results.json
```
